# Lyrics Explicit Mark для PulseSync

Автор — **@agencyofviolence**.

Аддон проверяет название и текст текущего трека и треков в списках, в том числе без штатной метки. Во время проверки рядом с названием крутится индикатор. После проверки появляется `EXPLICIT`, галочка или перечёркнутая `T`, если текст не найден. Все значки имеют непрозрачность 50%. Пока виден значок аддона, штатная и дублирующая метки Explicit в той же строке скрыты. Значок подмены трека от FckCensor остаётся видимым.

В контекстном меню плейлиста нажмите «Пропускать треки с матом или без текста», чтобы включить или выключить пропуск для всего плеера. Выбор сохраняется после перезапуска. При подтверждённой метке Explicit или результате «Текст песни не найден» плеер переходит к следующему треку. Проверка учитывает ругательства и сексуальную лексику, поэтому переключатель действует и на вторую категорию. Функция выключена по умолчанию.

## Общий список

Аддон проверяет подпись [общего списка](https://github.com/lenorio/EXECLIPTCHECKER/blob/main/verified-tracks.json) и использует совпадения по ID трека. Для остальных треков он читает локальный кеш, затем использует тексты PulseSync и LRCLIB. При недоступности списка или ошибке проверки подписи работают локальные источники.

## Как отправить свою выгрузку

1. Откройте **Настройки** в Яндекс Музыке и нажмите **«Экспортировать проверенные треки»**. Если установлен FckCensor, эта строка находится сразу под **«Очистить базу данных FckCensor»**.
2. В окне экспорта нажмите **«Сохранить JSON»** и выберите папку для файла `explicit-track-submission.json`. Если сохранить файл через окно не получается, нажмите **«Скопировать»** и сохраните скопированный текст в файл с тем же именем.
3. Откройте [Issues репозитория EXECLIPTCHECKER](https://github.com/lenorio/EXECLIPTCHECKER/issues) и нажмите **New issue**. Укажите заголовок **«Выгрузка проверенных треков»**.
4. Перетащите `explicit-track-submission.json` в поле описания и нажмите **Submit new issue**. Если загрузка файла недоступна, вставьте содержимое JSON в описание как блок кода.

Выгрузка содержит ID треков и результаты локальной проверки `explicit` или `clean`. Issues публичные, поэтому достаточно приложить выгрузку. Я, **@agencyofviolence**, проверю предложенные метки и добавлю одобренные записи в [общий подписанный список](https://github.com/lenorio/EXECLIPTCHECKER/blob/main/verified-tracks.json). После публикации аддон сможет использовать их без повторной проверки.

## Проверка и публикация для владельца

1. Сверьте предложенные результаты и оставьте в выгрузке одобренные записи.
2. Выполните `node scripts/shared-list.mjs merge путь-к-выгрузке.json`. Скрипт проверяет подпись текущего списка, добавляет новые ID и записывает подписанный `dist/verified-tracks.json`. Уже опубликованные записи сохраняются.
3. Загрузите полученный файл в `main` репозитория `lenorio/EXECLIPTCHECKER` под именем `verified-tracks.json`.

Закрытый ключ подписи хранится в `%LOCALAPPDATA%/LyricsExplicitMark/signing-key.pem`. Для команды подписи можно задать другой путь в переменной `EXPLICIT_SIGNING_KEY`. Храните резервную копию ключа в закрытом месте. Аддон содержит только открытый ключ.

## Сборка и установка

Нужны Node.js 20.19+ (в ветке 20.x) либо 22.12+, Yarn и Python 3 для упаковки.

```powershell
yarn install
yarn build
python -m zipfile -c dist/LyricsExplicitMark.zip dist/lyrics-explicit-mark/metadata.json dist/lyrics-explicit-mark/script.js dist/lyrics-explicit-mark/script.css dist/lyrics-explicit-mark/README.md dist/lyrics-explicit-mark/Assets
Move-Item dist/LyricsExplicitMark.zip dist/LyricsExplicitMark.pext -Force
```

Импортируйте `dist/LyricsExplicitMark.pext` в PulseSync. Для разработки используйте `yarn dev` или `yarn build:sync`. Формат архива описан в [импортёре PulseSync](https://github.com/PulseSync-LLC/PulseSync-client/blob/main/src/main/core/pextImporter.ts).

Метки зависят от разметки клиента. Проверка текстов использует словарь и может ошибаться. Если в списке нет идентификатора трека, аддон ищет текст по названию и исполнителю.
