# Интерфейс Lyrics Explicit Mark

Пункт контекстного меню плейлиста использует стандартную строку PulseSync. Кнопка экспорта стоит в списке настроек Яндекс Музыки, сразу после очистки базы FckCensor, когда она доступна. Свитч справа в строке меню показывает сохранённое состояние пропуска. Меню остаётся открытым при переключении. Названия и статусы отображаются по-русски. Значки результата стоят рядом с названием трека в общем контейнере заголовка и используют его цвет с непрозрачностью 50%. Для загрузки используется один вращающийся индикатор со статичным вариантом при включённом сокращении движения. Метка имеет доступное текстовое описание. При ошибке проверки штатная метка снова видна.
